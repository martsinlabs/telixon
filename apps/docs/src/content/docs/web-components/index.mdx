`@telixon/web-components` has three parts. [`<telixon-phone-field>`](/web-components/phone-field/)
turns the `<input>` inside it into a phone field the form submits and validates like a native
field. The user sees a formatted number while the form submits it in E.164. The input stays in the page, where your
labels, styles, and autofill apply to it. [`<telixon-region-picker>`](/web-components/region-picker/)
adds the flag and a searchable list of regions. [`<telixon-flag>`](/web-components/flag/) shows the
flag of a region. All three are custom elements built on [`@telixon/web-sdk`](/web-sdk/). They run
in every current browser and inside the markup of any framework.

The package depends on `@telixon/core` and `@telixon/web-sdk` and re-exports both. One import covers
every element, function, and type.

## The stylesheet

`@telixon/web-components/flags/flags.css` paints the flags, on the page and inside the picker. Import
it once, from the page's stylesheet or from the entry module of a bundled application:

```css
@import '@telixon/web-components/flags/flags.css';
```

## Define the elements

One call defines the three elements. On a server-rendered page it belongs in the client entry, as
[`defineTelixonElements`](/web-components/define/) describes:

```js
import { defineTelixonElements } from '@telixon/web-components';

defineTelixonElements();
```

At first the picker shows the United States flag with `+1` and the field shows the placeholder
`201-555-0123`. After typing `4155550132` the field shows `415-555-0132` while the value reads
`+14155550132`. Save submits `phone=+14155550132`. A partial number keeps the value at `null` and
blocks the submission with `This number is too short.` anchored at the input. Clear the field, pick
the United Kingdom, and type `2071838750`. The field then shows `20 7183 8750` with the value
`+442071838750`.

The field loads the engine the first time it connects, which the `engine-loading` state marks.
Until then the input is a plain input. An application that wants the engine earlier calls
[`ensureEngineReady`](/core/load-the-engine/), which the package re-exports, before the field appears.

## Browser support

The elements need form-associated custom elements, custom states, and the Popover API. Custom
states and the popover set the floor:

| Browser    | Version |
| ---------- | ------- |
| Chrome     | 125     |
| Edge       | 125     |
| Firefox    | 126     |
| Safari     | 17.4    |
| iOS Safari | 18.3    |
