[`createRegionList`](/web-sdk/region-list/#createregionlist) turns the engine's region data into
picker rows. [`createRegionPicker`](/web-sdk/region-picker/#createregionpicker) holds the open
state, the keyboard cursor, and the selection.
[`attachRegionPicker`](/web-sdk/region-picker/#attachregionpicker) wires a button, a search box,
and a list to it, while your render functions draw the rows and the button.

## Live demo

Open the picker. All 245 regions are in the list, with US, CA, and GB pinned on top. Search
`united` and the list narrows to three rows. The match runs over names, region codes, and calling
codes; `+44` finds the United Kingdom too. Pick a row and the button shows its flag and name, with
the status line reporting the selection. The arrow keys walk the rows from the search box, Enter
picks the active row, and Escape closes the list.

## The code

The demo and the source are the same three files. The markup is a button with a
[flag sprite](/web-sdk/flags/) cell and a name, a popup with the search box and an empty list, and
a status line.

The script creates two widgets. `createRegionList` builds the rows, with
[`prioritize`](/web-sdk/region-list/#regionlistoptions) pinning US, CA, and GB. `createRegionPicker`
takes the list and, without a phone input, keeps the selection itself.
[`select`](/web-sdk/region-picker/#select) seeds it with the United States.

`attachRegionPicker` wires the button, the search box, and the list to the picker and owns the
clicks, the keys, the outside press, and the ARIA attributes. The demo hands it three functions.
`renderOption` builds a row from a flag cell, the name, and the calling code, with
[`flagTransform`](/web-sdk/flags/#flagtransform) selecting the cell. `renderEmpty` builds the row
shown when the search matches nothing. `renderTrigger` puts the selected region's flag and name on
the button and writes the status line.
