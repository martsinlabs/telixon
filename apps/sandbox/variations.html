Telixon Variations

National

mode: 'national'. Region is chosen via the selector and stays fixed. The input holds only the national digits, formatted with the region's national mask (e.g. (415) 555-0123).

Resolved: n/a

International with plus

display: { callingCodeInInput: true, plusPrefix: true }. The user types the leading +, calling code, then national digits (e.g. +1 415-555-0123). Region resolves live from the calling code; no separate selector is shown.

Resolved: n/a

International without plus

display: { callingCodeInInput: true, plusPrefix: false }. Same as above but the input value starts with the calling code digits directly, no leading + (e.g. 1 415-555-0123).

Resolved: n/a

International split

display: { callingCodeInInput: false }. The calling code is rendered outside the input (in the selector); the input holds the national digits formatted with the international body mask (e.g. 415-555-0123, no parens). International resolution path applies.

Resolved: n/a
