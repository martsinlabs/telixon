Telixon Sandbox

Sandbox

A multi-page validation harness for @telixon/web-sdk. Each page exercises one primitive in real browser conditions that headless tests cannot reach: native IME, mobile keypads, paste, undo, selection edits, and cross-browser beforeinput semantics.

Demos

  • PhoneInput Bind a phone-formatted controller to an <input>. Mode toggle, country, initial value, filters, undo/redo, seal, duplicate-attach guard, live state and PhoneNumber readouts.
  • CountryList Headless country picker pipeline. Search, locale switch, country and number-type filters, sort options, prioritization, custom data factory, force refresh.
  • Variations Four display modes side by side showing how the display config shapes the input value: national, international with plus, international without plus, and international split.
