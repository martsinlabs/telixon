# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Maintainers will enforce the Covenant. Report unacceptable behavior through the
[GitHub Security Advisory form](https://github.com/martsinlabs/telixon/security/advisories/new).
Reports are kept confidential.
