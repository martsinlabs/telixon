# Web Components quick start

The smallest page with `@telixon/web-components`: a phone field with a region picker inside a form,
and the value and the submitted number shown below it.

**[Open in StackBlitz](https://stackblitz.com/github/martsinlabs/telixon/tree/main/examples/web-components/quick-start)**

## Run locally

```bash
npm install
npm start
```

Vite serves the field at http://localhost:5173.

The page installs the published package from npm, which keeps it outside the pnpm workspace. A
weekly workflow builds it the same way.
