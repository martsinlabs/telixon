# Angular quick start

The smallest Angular application with `@telixon/angular`: a phone field with a region picker on a
reactive form control, and the form value and error shown below it.

**[Open in StackBlitz](https://stackblitz.com/github/martsinlabs/telixon/tree/main/examples/angular/quick-start)**

## Run locally

```bash
npm install
npm start
```

`ng serve` serves the field at http://localhost:4200.

The application installs the published packages from npm, which keeps it outside the pnpm
workspace. A weekly workflow builds it the same way.
