# Angular Signal Forms with Material quick start

The phone field with a region picker inside `mat-form-field`, bound to a Signal Form through
`[formField]`. Material supplies the floating label, outline, hint and error state. The model value
is shown below the field.

**[Open in StackBlitz](https://stackblitz.com/github/martsinlabs/telixon/tree/main/examples/angular/quick-start-signal-forms-material)**

## Run locally

```bash
npm install
npm start
```

`ng serve` serves the field at http://localhost:4200.

The application installs the published packages from npm, which keeps it outside the pnpm
workspace. A weekly workflow builds it the same way.
