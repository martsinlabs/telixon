# Angular Signal Forms quick start

The smallest Angular application with `@telixon/angular` on a Signal Form: a phone field bound
through `[formField]`, a region picker next to it, and the model value and error shown below.

**[Open in StackBlitz](https://stackblitz.com/github/martsinlabs/telixon/tree/main/examples/angular/quick-start-signal-forms)**

## Run locally

```bash
npm install
npm start
```

`ng serve` serves the field at http://localhost:4200.

The application installs the published packages from npm, which keeps it outside the pnpm
workspace. A weekly workflow builds it the same way.
